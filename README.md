# Sistema de Soporte Técnico y Monitoreo de Redes

Proyecto académico de Teleprocesos y Sistemas Avanzados de Bases de Datos de la UNEFANB, Núcleo Miranda, Extensión Santa Teresa del Tuy.

## Objetivo
Desarrollar un sistema multiusuario cliente-servidor para gestionar incidencias de soporte técnico y monitorear equipos conectados a una red.

## Funcionalidades previstas
- Inicio de sesión, recuperación y cambio de contraseña.
- Usuarios con roles y permisos.
- Registro y monitoreo de equipos.
- Gestión de incidencias técnicas.
- Reportes y base de datos.
- Comunicación cliente-servidor mediante TCP/IP.

## Estado
Proyecto en fase de planificación y diseño. Desarrollo colaborativo de cuatro estudiantes.
